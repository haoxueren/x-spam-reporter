# X 一键举报助手

在 X/Twitter 评论区**自动查找并举报**包含指定关键词的评论（举报类别：**垃圾信息**）。
纯全自动模式：自动滚动加载更多评论 → 逐条走完举报流程 → 人性化随机间隔，降低风控触发概率。

## 功能特性

- 🔍 **关键词匹配**：支持多个关键词（每行一个），自动匹配评论区所有含关键词的评论
- 🤖 **全自动举报**：自动走完 X 举报流程：更多菜单 → 举报帖子 → 垃圾信息 → 下一步 → 完成
- 📜 **自动滚动加载**：自动向下滚动，加载并检查更多评论
- 🚫 **防重复**：已举报账号本地持久化记录（chrome.storage），跨页面/跨域名不重复举报
- ⏱ **人性化间隔**：两层节奏防过快——
  1. **步骤间**：单条举报流程内每次点击前随机停顿 400~900ms（模拟真人手速）
  2. **评论间**：每条评论之间随机延迟（间隔可调 2~30 秒，默认 4 秒 + 0~3 秒抖动）
  检测到 X 频率限制（CD）时自动停止
- 🛡 **失败保护**：失败自动跳过该账号，失败过多自动停止，避免死循环
- 🖥 **实时状态**：弹窗内实时显示进度、日志、已举报账号列表

## 安装

1. 打开 Chrome/Edge/Chromium，访问 `chrome://extensions`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（`x-spam-reporter`）
4. 打开任意 X 帖子页面，点击工具栏中的插件图标

## 使用

1. 打开目标帖子的评论区页面（如 `https://x.com/xxx/status/123`）
2. 点击插件图标，填写举报关键词（默认 `福不黑`）
3. 设置间隔（建议 ≥ 4 秒）和上限条数
4. 点击 **▶ 开始自动举报**
5. 等待运行完成；可随时点 **⏹ 停止**
6. 运行结束后，评论会自动滚动到底部并停止

> 建议保持插件弹窗打开以观察进度；也可以关闭弹窗，运行会继续。

## 工作原理

插件在 X 页面注入 content script，核心流程：

```
找到含关键词的评论卡片
  → 提取账号 handle（防重复）
  → 点击"更多"(...) 按钮
  → 点击"举报帖子"
  → 对话框中选择"垃圾信息"
  → 点击"下一步"
  → 点击"完成"（提交成功）
  → 记录账号，随机等待后处理下一条
```

全部选择器均在真实页面验证通过（2026-08 于 x.com）。

## 注意事项与风险

| 事项 | 说明 |
|------|------|
| ⚠️ 频率限制 | X 对举报有 rate limit（CD）。间隔设置太短会被限流，插件检测到后会**自动停止**，请过几分钟再运行 |
| ⚠️ 账号风险 | 高频自动化操作违反 X 用户协议，请控制频率、合理使用；如担心风险建议间隔 ≥ 8 秒 |
| 🔁 重复举报 | 已举报账号会持久化记录；如需重新举报可在弹窗中 **清空已举报记录** |
| 📄 隐私 | 插件无任何网络请求，仅在本机浏览器内操作，数据只存于本地 chrome.storage |

## 开发

- 修改后到 `chrome://extensions` 点击插件卡片上的 **重新加载** 即可生效
- 关键词、间隔等配置会保存在浏览器本地，重开弹窗后自动恢复
- 如需调试，右键插件图标 → 检查弹出内容，或打开页面开发者工具查看 content script 日志
